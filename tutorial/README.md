# Tutorial

## Introduction
* `app/`: application structure
* `view/`: visualising structure
* `node/`: general node properties
* `entity/`: about node entities
* `query/`: finding code patterns
* `qresults/`: operations on query results
* `refs/`: references and types
* `loops/`: loop properties
* `functions/`: function declarations and calls
* `conditionals/`: *if* statements

## Intermediate
* `unparse/`: translating AST nodes to source-code
* `instrumentation/`: code manipulation
* `pragmas/`: custom pragma annotations
* `attributes/`: source attributes (C++)
* `pmaps/`: property maps

## Advanced
* `dfs/`: tree visiting algorithms [n/a]
* `tokens/`: accessing tokens
* `exec/`: ast execution and reporting
* `tracking/`: node tracking between commits/clone

## Runtime
* `memory/`: example on how to use instrumentation to extract memory allocation information using Artisan runtime C++ library

## Workflow
* a set of common examples explaining how to employ Artisan
